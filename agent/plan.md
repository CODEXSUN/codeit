# Planning and approval

Use [shared governance](../../../assist/GOVERNANCE.md) and [Codeit agent rules](../docs/agent-rules.md) to set scope and ownership. The user's current instructions take precedence.

## Prepare a plan

1. State the problem and intended outcome.
2. Identify the owning module, affected data, and relevant contracts.
3. Record acceptance criteria, verification, dependencies, and known risks.
4. Split work into tasks with clear outcomes.
5. Save and review the plan before approval.

Codeit approves the saved plan and pins its project folder and requested permissions. It checks those settings before work, review, and resolution. A supervisor proposal or an unsaved draft is not an approved plan. Codeit requires explicit actions to approve, start, review, and resolve work.

If the user requires planning before implementation, wait for authorization before changing code. The plan does not grant permission for unrelated operations. See the [module contract](../docs/templates/module-contract.md), [event contract](../docs/templates/event-contract.md), and [verification](../docs/templates/verification.md) templates.
