# Skills

A skill is a set of instructions in a `SKILL.md` file. The active agent environment supplies the available skills and their locations. Codeit does not currently provide a skill registry or automatically load skills through this document.

1. Follow an explicitly requested skill when it is available and applicable.
2. Read its `SKILL.md` and any needed referenced resources before use.
3. Apply relevant skills when they improve the task.
4. Follow the user's instructions and higher-priority instructions if they conflict with skill guidance.
5. Report a missing required skill or a constraint that prevents completion.

Do not treat a skill as authorization to ignore repository boundaries or fabricate a server connection. For the shared rules, see [governance](../../../assist/GOVERNANCE.md) and the [agent guide](../../../assist/AGENT.md). For Codeit rules, see [Rule Book](../docs/rule-book.md).
